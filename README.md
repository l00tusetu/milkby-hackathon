# Цифровая витрина «Молочный Мир»

Веб-приложение — каталог молочной продукции ОАО «Молочный Мир» с версиями на русском, белорусском, английском и китайском языках. Витрина предназначена для покупателей, оптовых клиентов и экспортных партнёров.

## Возможности

- каталог товаров и категорий с поиском, фильтрами и сортировкой;
- страницы товаров с описаниями, характеристиками, фасовками и сроками хранения;
- умный подбор продукции по запросу;
- B2B-форма запроса информации и выгрузка спецификации товара;
- разделы новостей, о компании, для партнёров и экспорта;
- демонстрационная панель администратора для редактирования контента;
- сохранение выбранного языка и части изменений в локальном хранилище браузера.

## Локальный запуск

### Требования

- Node.js `20.19+` или `22.12+`;
- npm.

### Установка и запуск

В корне проекта выполните:

```bash
npm ci
npm run dev
```

Откройте адрес, указанный Vite в терминале. По умолчанию это [http://localhost:3000](http://localhost:3000).

Сервер разработки настроен на прослушивание сетевых интерфейсов компьютера. Чтобы открыть страницу на другом устройстве в той же сети, используйте локальный IP компьютера и порт `3000`, например `http://192.168.1.10:3000`.

Остановить сервер можно сочетанием `Ctrl+C` в терминале.

### Полезные команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Запустить сервер разработки с горячей перезагрузкой |
| `npm run lint` | Проверить TypeScript (`tsc --noEmit`) |
| `npm run build` | Собрать production-версию в `dist/` |
| `npm run preview` | Локально просмотреть собранную версию |

Чтобы проверить production-сборку:

```bash
npm run build
npm run preview
```

Vite выведет адрес предпросмотра в терминал (по умолчанию `http://localhost:4173`).

### Переменные окружения

Для обычного локального запуска сайта файл с секретами не требуется. В проекте есть `.env.example` с переменными для окружения AI Studio (`GEMINI_API_KEY`, `APP_URL`); не добавляйте реальные ключи в Git. Перед использованием какой-либо интеграции проверьте, что она подключена в коде приложения.

## Разделы сайта

Приложение использует `HashRouter`: адреса страниц содержат `#/`, например:

- `http://localhost:3000/#/` — главная;
- `http://localhost:3000/#/catalog` — каталог;
- `http://localhost:3000/#/product/syr-gubert` — карточка товара;
- `http://localhost:3000/#/news` — новости;
- `http://localhost:3000/#/export` — экспорт;
- `http://localhost:3000/#/partners` — партнёрам;
- `http://localhost:3000/#/admin` — панель администратора.

Язык можно переключить в интерфейсе. Поддерживаются `ru`, `be`, `en` и `zh`.

## Панель администратора

В приложении предусмотрен демонстрационный вход:

- логин: `admin` (или `admin@milk.by`);
- пароль: `milk2026`.

Эти учётные данные заданы в клиентском коде и предназначены только для демонстрации. Панель не обеспечивает серверную аутентификацию или разграничение доступа и не должна использоваться как защищённая административная система в production.

Контент и настройки каталога сохраняются в `localStorage` текущего браузера. Это локальные демонстрационные данные: они не синхронизируются между устройствами или пользователями и могут быть сброшены очисткой данных сайта.

## Структура проекта

```text
src/
  components/   Общие UI-компоненты и компоненты администратора
  data/         Начальные данные товаров, категорий, новостей и переводов
  hooks/        Контексты языка, авторизации и состояния каталога
  pages/        Страницы приложения
  types/        Общие типы TypeScript
  utils/        Поиск, экспорт спецификаций и другие функции
parser/         Необязательные Python-скрипты сбора данных с milk.by
public/         Статические файлы, доступные без импорта
```

Основные точки входа: `src/main.tsx` и `src/App.tsx`. Начальные данные каталога и локализованные тексты находятся в `src/data/`.

## Необязательные скрипты сбора данных

В `parser/` находятся отдельные Python-скрипты для сбора каталога и новостей с `milk.by`. Они не нужны для запуска веб-приложения. Для их запуска установите зависимости:

```bash
python -m pip install requests beautifulsoup4 urllib3
```

Затем из каталога `parser/` запустите нужный скрипт:

```bash
python parse.py --help
python parse_news.py --help
```

Скрипты поддерживают ограничение количества записей и настройку параллельной загрузки; доступные параметры перечислены в справке.
